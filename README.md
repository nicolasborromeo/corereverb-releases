# CoreReverb releases

Public installers for CoreReverb (macOS). Each version is tagged; the installer for a version lives at `https://github.com/nicolasborromeo/corereverb-releases/raw/<tag>/CoreReverb-macOS-<version>.pkg`

| Version | Installer | SHA-256 |
|---|---|---|
| **1.0.1 (beta, current)** | [CoreReverb-macOS-1.0.1.pkg](https://github.com/nicolasborromeo/corereverb-releases/raw/v1.0.1/CoreReverb-macOS-1.0.1.pkg) | `4c121a402c3588b0ff979f26949b0a40a5a8748d939bc2c300ad8c9ccbeb23c5` |
| 1.0.0 (superseded) | [CoreReverb-macOS-1.0.0.pkg](https://github.com/nicolasborromeo/corereverb-releases/raw/v1.0.0/CoreReverb-macOS-1.0.0.pkg) | `5daab05a88081b3f632d343cad84a9877c8313f94470e0b9e1d95cdc7fde60fa` |

1.0.1 fixes the knob graphics not showing (1.0.0 shipped one image file unreadable) and renames the plugin from CoreVerb to CoreReverb. Installing 1.0.1 removes the old CoreVerb copies automatically.

Run the .pkg, then open CoreReverb in your DAW and paste the license key from your invite email.
