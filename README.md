Public installers for CoreReverb (macOS). Each version is tagged; the installer for a version lives at `https://github.com/nicolasborromeo/corereverb-releases/raw/<tag>/CoreReverb-macOS-<version>.pkg`

1.1.0 shows how many Advisor questions are left and lets you get more from the plugin, picks up a bought pack without a manual refresh, adds a new activation screen and refreshed knob and menu styling, and improves Advisor answers. Installing it replaces 1.0.1 in place.

1.0.1 fixes the knob graphics not showing (1.0.0 shipped one image file unreadable) and renames the plugin from CoreVerb to CoreReverb. Installing 1.0.1 removes the old CoreVerb copies automatically.

Run the .pkg, then open CoreReverb in your DAW and paste the license key from your purchase email.
